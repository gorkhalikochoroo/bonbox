# Breach register (GDPR Art. 33(5))

Every breach is recorded, including those not notified. Categories and counts only, never names/e-mails/phones/allergy notes.

How to use it: open an entry as soon as personal data *may* be involved
(see `INCIDENT.md`, section d), fill the columns as facts arrive, and close it
after the post-incident review. An entry that turns out not to be a breach
stays, with the reason in "Measures taken".
